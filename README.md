## 🚀 Featured project

### [Lumora](https://github.com/kant-sompong/Lumora)

![Python](https://img.shields.io/badge/python-3.10%2B-3776ab?style=flat-square)
![GTK](https://img.shields.io/badge/GTK-3-4a86cf?style=flat-square)
![Qt](https://img.shields.io/badge/Qt-6%20%2F%20PySide6-41cd52?style=flat-square)
![Platforms](https://img.shields.io/badge/platforms-Windows%20%7C%20Linux-2f6feb?style=flat-square)
![License](https://img.shields.io/badge/license-MIT-3fb950?style=flat-square)

A desktop app for the Internet Archive's Linux games collection, with a local library, a persistent download queue and a TMDB-powered Movies & TV section.

- **Browse:** search, filters (genre, size, year, licence, format), sorting, cover grid or list, lazy-loaded artwork
- **Library:** manifests per game, favourites, checksum verification, duplicate finder, export/import
- **Downloads:** persistent queue with pause/resume, segmented Range transfers, disk-space preflight, magnet links via a built-in BitTorrent engine
- **Movies & TV:** Continue Watching, season/episode picker, provider picker, embedded playback
- **Safety first:** nothing runs automatically, no elevated launches, launches confined to the download folder, API keys kept in the OS keyring
- **Engineering:** GitHub Actions CI that runs tests and builds the Windows ZIP, installer and Linux tarball, plus a headless Qt test suite
